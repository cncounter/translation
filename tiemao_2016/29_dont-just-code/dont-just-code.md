# 别只顾着写代码:来自编程大师的职业建议

> 原文: Don't just code: Career advice from the programming masters

## 开发技术创始人 Eich、van Rossum、Johnson、Hickey 和 Schleuter 给编程新人的建议

作为一种职业道路,软件开发再热门不过了。[编程语言正在激增](http://www.infoworld.com/article/3076097/application-development/fresh-and-functional-5-new-languages-to-watch.html),而美国劳工部劳工统计局预测,对开发者的需求[将在 2014 到 2024 年间以 17% 的速度增长](http://www.bls.gov/ooh/computer-and-information-technology/software-developers.htm) —— 远高于所有职业 7% 的平均水平。

正因如此,学生和非技术专业人士纷纷考虑转行做编程也就不足为奇了。但准开发者们究竟应当如何准备,才能抓住对程序员日益增长的需求? 我们请教了软件开发领域的几位大人物,请他们谈谈年轻程序员应该怎么做。受访者包括 JavaScript 的创造者 [Brendan Eich](http://www.infoworld.com/article/3048502/javascript/qa-javascript-creator-brendan-eich-puts-brave-face-on-the-web.html)、Clojure 创始人 [Rich Hickey](http://www.infoworld.com/article/3033912/application-development/functional-languages-what-they-are-where-theyre-going.html)、Spring Framework 的缔造者 [Rod Johnson](http://www.infoworld.com/article/2617514/java/oracle-to-spring-developers--convert-to-java-ee.html)、Npm 创始人 [Isaac Schlueter](http://www.infoworld.com/article/3035041/application-development/npm-inc-explores-foundation-for-javascript-installer.html),以及 Python 语言的发明者 [Guido van Rossum](http://www.infoworld.com/article/3078633/application-development/qa-guido-van-rossum-on-pythons-next-steps.html)。

以下是他们就教育机会、应精通的语言,以及如今怎样才算一名优秀程序员所给出的看法。

### 关于教育

当关于计算机科学学位价值的争论仍在继续时,这些编程界的领军人物都强调全面教育的重要性,主张花大量时间学习控制台之外的学科。

"生活中最大的挑战并没有技术上的解决办法,"Eich 说,"所以学习历史、文学、艺术以及其他各类人文知识,比学任何与计算机有关的东西都重要。"

Hickey 表示赞同,并把编程放到一个更广阔的视角中。

"从历史的长河来看,编程是一项非常新的事业,"他说,"我们不该自以为已经懂得如何最好地去从事它。"

相反,Hickey 建议去追求其他教育方面的兴趣,以帮助理解编程能够解决哪些类型的问题。

"最好的程序员是那些能够理解、沟通并解决自己所处领域问题的人,"他说,"软件只是用来做这件事的工具。"

Johnson 也认为,准程序员应当去了解计算机实验室和数学系之外的学科,以完善自己的教育,因为归根结底,"编程关乎的是人,而不是数学。"

即便谈到是否攻读计算机科学学位,Johnson 也"很纠结"。

"人们用到的多半是工作中学会的东西,"Johnson 说,"良好的计算机科学教育确实有价值,但我见过很多背景各异的优秀程序员。"

Van Rossum 表示赞同。"有些人拿着英语学位,去参加一次 Django Girls 工作坊,从此就成了 Web 开发者,"他说,"也有人读完传统的四年大学,主修计算机科学。"

当然,Johnson 说,即便在现实世界中,理论也确实有它的用武之地。

"昨天我就用到了当学生时学过的一些编译原理,它帮我漂亮而稳健地解决了我遇到的问题,"他说,"但这种情况并不常见。"

Eich 认为,更有价值的是把数学当作数学来学,而不是把它当作学习计算机科学理论的敲门砖。

"编程并不全是数学,有时几乎跟数学没什么关系,"他说,"但如果你擅长数学,趁年轻就把它当作数学来学。别太操心编程。"

Van Rossum 谈得更深入一些,他推荐"那种能培养逻辑思维的数学"。

对于在成为程序员之前先接受通识教育,Schlueter 另有一套说法:"如果能负担得起,文理教育是高中毕业后度过四年的绝佳方式,"他说,"你这一生不会再有另一段时间,可以这样长时间地基本上只顾着闲混和派对,还得到社会认可。"

如果你真接受了他的建议,Schlueter 还给出了一些极其务实的建议:"公立学校便宜得多,助学贷款可不是闹着玩的,所以要节俭,"他说,"尽力去争取你能拿到的任何奖学金或助学金。"

Schlueter 主张,写作是成为一名强大程序员的关键一环。

"无论你上不上大学,都要尽早挤出时间大量阅读文学和哲学,一手资料和二手资料都要读,并且尽可能多写,"他说,"如果你不上大学,那就尽快花钱请一位写作家教,让他给你布置作业,再帮你打磨。这份工作是在互联网上进行的,而书面文字正是人们在网上沟通的方式。你写得越有效,你就越占优势。"

### 关于编程语言

等你真正坐下来编程时,应该先考虑哪些语言呢?

"OCaml、Haskell、Rust、C++、TypeScript、JS、Racket —— 或者 [SICP](https://mitpress.mit.edu/sicp/full-text/book/book.html) 里用的 Scheme,"Eich 建议道,"显然我并不指望每个人都去学这些编程语言。但只要学上几门,在合适的时间和场合就很有用,尤其是对有兴趣和天分的本科生来说。"

Hickey 也建议采用多语言的方法,但对于如何从众多语言中挑选出一组有代表性的组合,他给出了更具哲学意味的看法。

"[挑一门]能清楚展现计算机如何工作的语言(C),一门把它封装起来的语言(Haskell、Prolog),一门优秀的静态类型函数式语言(又是 Haskell,也行),再加一门偏函数式的优秀动态语言。我个人偏爱 Clojure,"他说。

Johnson 建议学习思路截然相反的语言。

"语言会影响你对编程的思考,所以重要的是学习不止一门语言,而且要学思路不同的语言,"他说,"比如,一门面向对象语言加一门函数式语言,而不是像 Java 和 C# 这样的组合。"

"当然,我会说 Python 是一门很好的入门语言,"van Rossum 说,"紧接着就会出现该用哪个 Python 版本的问题,我会说从 Python 3 开始。如果今后的工作或项目需要,事后再学 Python 2 也很容易。如果你从零开始,Python 3 无疑是更好的语言。"

Johnson 还建议年轻开发者[去看看 Swift](http://www.infoworld.com/article/3083442/development-tools/apples-swift-3-developer-preview-arrives-for-macos-and-linux.html)。

"它是一门很棒的现代语言,包含了很多好想法,我认为我们会看到它从 iOS 扩散到其他平台,"他说,"JavaScript 非常有用,虽然不太适合作为第一门语言。Java 值得一学。它学起来并不特别难,热度持续上升,而且 JVM 无处不在。"

### 关于实践中的编程

当你手上做过几个项目之后,如何把技能提升到下一个层次?

Eich 建议通过研读优秀的代码,向早期(以及当下)的大师学习。

"读高质量的代码,有时甚至可以打印在纸上,这样你能写批注、用彩笔标注,"Eich 说,"说到高质量代码,我认为经典仍然是 Kernighan & Ritchie 的[_《C 程序设计语言》_](https://www.amazon.com/Programming-Language-Brian-W-Kernighan/dp/0131103628/ref=sr_1_1?ie=UTF8&qid=1466554341&sr=8-1&keywords=The+C+Programming+Language%2C),不过这就暴露我的年纪了。还有[_《Unix 编程环境》_](https://www.amazon.com/Unix-Programming-Environment-Prentice-Hall-Software/dp/013937681X)。比较新近、值得一读的代码:'[Solving Every Sudoku Puzzle](http://norvig.com/sudoku.html)' 或者 [norvig.com](http://norvig.com/) 上的任何东西,真的。"

Hickey 建议要有耐心,并做好准备。

"编程最重要的部分发生在离开电脑的时候,"他说,"动手之前先想清楚你要做什么,而不是一直敲键盘,直到弄出一个看起来能用的东西。"

但一旦你真坐到了键盘前,Eich 建议要坚持下去:"我至今仍觉得 Ken Thompson 那句'拿不准时,就用蛮力'永远管用。别卡住!"

Johnson 给出了另一个值得研读的代码来源:开源。

"你可以从优秀开源项目的代码中学到很多东西,而且有很多参与贡献的机会,"他说,"这也有助于培养协作能力。我见过这种情况成为从学校走向业界的宝贵桥梁,或者从一份无聊的工作走向更有意思工作的跳板。"

至于对规划未来职业的年轻程序员来说,那些有意思的工作可能在哪里,Eich 建议"航天、3D 打印、3D 渲染、生物信息学、Web"。

Van Rossum 建议在选择工作时不要将就:"不要接受那些你认为自己不会做得开心的活。程序员的工作多得是。找一件你真正享受做的事情,因为这样你会更高效、更快乐,对所有人都会更好。"

Hickey 表示赞同。"编程的一大好处是,几乎所有的领域都需要软件。挑一个你感兴趣的领域吧,"他说。

无论你选了什么,Schlueter 建议你要放眼长远。

"如果你有耐心、坚持学习,编程其实是相当容易的。但最终,所有的职业道路要么走到死胡同,要么通向某种形式的管理,"他说,"即使你专注于技术,最终你也会去带领别人,这样你才能有更大的影响范围,成就更多。"

为此,Schlueter 建议你一路学着读一些关于领导力、沟通和商业的书。

"那些东西比看上去要复杂得多,而且极其重要,"他说。
