## 4.6. Methods

## 4.6. 方法

Each method, including each instance initialization method ([§2.9](https://docs.oracle.com/javase/specs/jvms/se8/html/jvms-2.html#jvms-2.9)) and the class or interface initialization method ([§2.9](https://docs.oracle.com/javase/specs/jvms/se8/html/jvms-2.html#jvms-2.9)), is described by a `method_info` structure.

每个方法, 包括每个实例初始化方法 ([§2.9](https://docs.oracle.com/javase/specs/jvms/se8/html/jvms-2.html#jvms-2.9)) 以及类或接口的初始化方法 ([§2.9](https://docs.oracle.com/javase/specs/jvms/se8/html/jvms-2.html#jvms-2.9)), 都由一个 `method_info` 结构来描述。

No two methods in one `class` file may have the same name and descriptor ([§4.3.3](#jvms-4.3.3)).

同一个 `class` 文件中, 不能有两个方法具有相同的名称和描述符 ([§4.3.3](#jvms-4.3.3))。

The structure has the following format:

该结构具有以下格式:

```
method_info {
    u2             access_flags;
    u2             name_index;
    u2             descriptor_index;
    u2             attributes_count;
    attribute_info attributes[attributes_count];
}

```

The items of the `method_info` structure are as follows:

`method_info` 结构中的项如下:

- access_flags

  The value of the `access_flags` item is a mask of flags used to denote access permission to and properties of this method. The interpretation of each flag, when set, is specified in [Table 4.6-A](#jvms-4.6-200-A.1).

  `access_flags` 项的值是一个标志位掩码, 用来表示该方法的访问权限以及相关特性。每个标志位被设置时的含义在 [Table 4.6-A](#jvms-4.6-200-A.1) 中指定。

**Table 4.6-A. Method access and property flags**

**Table 4.6-A. 方法的访问与特性标志**

| Flag Name         | Value  | Interpretation                           |
| ----------------- | ------ | ---------------------------------------- |
| `ACC_PUBLIC`      | 0x0001 | Declared `public`; may be accessed from outside its package. |
| `ACC_PRIVATE`     | 0x0002 | Declared `private`; accessible only within the defining class. |
| `ACC_PROTECTED`   | 0x0004 | Declared `protected`; may be accessed within subclasses. |
| `ACC_STATIC`      | 0x0008 | Declared `static`. |
| `ACC_FINAL`       | 0x0010 | Declared `final`; must not be overridden ([§5.4.5](https://docs.oracle.com/javase/specs/jvms/se8/html/jvms-5.html#jvms-5.4.5)). |
| `ACC_SYNCHRONIZED`| 0x0020 | Declared `synchronized`; invocation is wrapped by a monitor use. |
| `ACC_BRIDGE`      | 0x0040 | A bridge method, generated by the compiler. |
| `ACC_VARARGS`     | 0x0080 | Declared with variable number of arguments. |
| `ACC_NATIVE`      | 0x0100 | Declared `native`; implemented in a language other than Java. |
| `ACC_ABSTRACT`    | 0x0400 | Declared `abstract`; no implementation is provided. |
| `ACC_STRICT`      | 0x0800 | Declared `strictfp`; floating-point mode is FP-strict. |
| `ACC_SYNTHETIC`   | 0x1000 | Declared synthetic; not present in the source code. |

| Flag Name         | Value  | Interpretation                           |
| ----------------- | ------ | ---------------------------------------- |
| `ACC_PUBLIC`      | 0x0001 | 声明为 `public`; 可以被其他包(package)所访问。 |
| `ACC_PRIVATE`     | 0x0002 | 声明为 `private`; 只能在定义该方法的类内部访问。 |
| `ACC_PROTECTED`   | 0x0004 | 声明为 `protected`; 可以在子类(subclasses)中访问。 |
| `ACC_STATIC`      | 0x0008 | 声明为 `static`。 |
| `ACC_FINAL`       | 0x0010 | 声明为 `final`; 不能被覆盖(overridden) ([§5.4.5](https://docs.oracle.com/javase/specs/jvms/se8/html/jvms-5.html#jvms-5.4.5))。 |
| `ACC_SYNCHRONIZED`| 0x0020 | 声明为 `synchronized`; 调用时会被 monitor 的使用所包裹。 |
| `ACC_BRIDGE`      | 0x0040 | 桥接方法(bridge method), 由编译器生成。 |
| `ACC_VARARGS`     | 0x0080 | 声明为带有可变数量的参数。 |
| `ACC_NATIVE`      | 0x0100 | 声明为 `native`; 由 Java 之外的语言实现。 |
| `ACC_ABSTRACT`    | 0x0400 | 声明为 `abstract`; 不提供实现。 |
| `ACC_STRICT`      | 0x0800 | 声明为 `strictfp`; 浮点模式为 FP-strict。 |
| `ACC_SYNTHETIC`   | 0x1000 | 声明为 synthetic(合成); 即在 Java 源代码中不存在。 |

  Methods of classes may have any of the flags in [Table 4.6-A](#jvms-4.6-200-A.1) set. However, each method of a class may have at most one of its `ACC_PUBLIC`, `ACC_PRIVATE`, and `ACC_PROTECTED`flags set (JLS §8.4.3).

  类的方法可以设置 [Table 4.6-A](#jvms-4.6-200-A.1) 中的任意标志位。但是, 类的每个方法最多只能设置 `ACC_PUBLIC`、`ACC_PRIVATE` 和 `ACC_PROTECTED` 中的一个标志位 (JLS §8.4.3)。

  Methods of interfaces may have any of the flags in [Table 4.6-A](#jvms-4.6-200-A.1) set except `ACC_PROTECTED`, `ACC_FINAL`, `ACC_SYNCHRONIZED`, and `ACC_NATIVE` (JLS §9.4). In a `class` file whose version number is less than 52.0, each method of an interface must have its `ACC_PUBLIC` and `ACC_ABSTRACT` flags set; in a `class` file whose version number is 52.0 or above, each method of an interface must have exactly one of its `ACC_PUBLIC` and `ACC_PRIVATE` flags set.

  接口的方法可以设置 [Table 4.6-A](#jvms-4.6-200-A.1) 中的任意标志位, 但 `ACC_PROTECTED`、`ACC_FINAL`、`ACC_SYNCHRONIZED` 和 `ACC_NATIVE` 除外 (JLS §9.4)。在版本号小于 52.0 的 `class` 文件中, 接口的每个方法都必须设置 `ACC_PUBLIC` 和 `ACC_ABSTRACT` 标志位; 在版本号为 52.0 或以上的 `class` 文件中, 接口的每个方法必须恰好设置 `ACC_PUBLIC` 和 `ACC_PRIVATE` 中的一个标志位。

  If a method of a class or interface has its `ACC_ABSTRACT` flag set, it must not have any of its `ACC_PRIVATE`, `ACC_STATIC`, `ACC_FINAL`, `ACC_SYNCHRONIZED`, `ACC_NATIVE`, or `ACC_STRICT`flags set.

  如果类或接口的某个方法设置了 `ACC_ABSTRACT` 标志位, 则不能设置 `ACC_PRIVATE`、`ACC_STATIC`、`ACC_FINAL`、`ACC_SYNCHRONIZED`、`ACC_NATIVE` 或 `ACC_STRICT` 中的任何标志位。

  Each instance initialization method ([§2.9](https://docs.oracle.com/javase/specs/jvms/se8/html/jvms-2.html#jvms-2.9)) may have at most one of its `ACC_PUBLIC`, `ACC_PRIVATE`, and `ACC_PROTECTED` flags set, and may also have its `ACC_VARARGS`, `ACC_STRICT`, and `ACC_SYNTHETIC` flags set, but must not have any of the other flags in [Table 4.6-A](#jvms-4.6-200-A.1) set.

  每个实例初始化方法 ([§2.9](https://docs.oracle.com/javase/specs/jvms/se8/html/jvms-2.html#jvms-2.9)) 最多只能设置 `ACC_PUBLIC`、`ACC_PRIVATE` 和 `ACC_PROTECTED` 中的一个标志位, 也可以设置 `ACC_VARARGS`、`ACC_STRICT` 和 `ACC_SYNTHETIC` 标志位, 但不能设置 [Table 4.6-A](#jvms-4.6-200-A.1) 中的任何其他标志位。

  Class and interface initialization methods are called implicitly by the Java Virtual Machine. The value of their `access_flags` item is ignored except for the setting of the `ACC_STRICT` flag.

  类初始化方法和接口初始化方法由 Java 虚拟机隐式调用。除了 `ACC_STRICT` 标志位的设置之外, 它们的 `access_flags` 项的值会被忽略。

  The `ACC_BRIDGE` flag is used to indicate a bridge method generated by a compiler for the Java programming language.

  `ACC_BRIDGE` 标志位用来表示由 Java 编程语言编译器生成的桥接方法。

  The `ACC_VARARGS` flag indicates that this method takes a variable number of arguments at the source code level. A method declared to take a variable number of arguments must be compiled with the `ACC_VARARGS` flag set to 1. All other methods must be compiled with the `ACC_VARARGS` flag set to 0.

  `ACC_VARARGS` 标志位表示该方法在源代码层面接受可变数量的参数。声明为接受可变数量参数的方法, 编译时必须将 `ACC_VARARGS` 标志位设置为 1。所有其他方法编译时必须将 `ACC_VARARGS` 标志位设置为 0。

  The `ACC_SYNTHETIC` flag indicates that this method was generated by a compiler and does not appear in source code, unless it is one of the methods named in [§4.7.8](#jvms-4.7.8).

  `ACC_SYNTHETIC` 标志位表明该方法是由编译器生成的, 在源代码中并不存在, 除非它是 [§4.7.8](#jvms-4.7.8) 中列出的方法之一。

  All bits of the `access_flags` item not assigned in [Table 4.6-A](#jvms-4.6-200-A.1) are reserved for future use. They should be set to zero in generated `class` files and should be ignored by Java Virtual Machine implementations.

  `access_flags` 项中未在 [Table 4.6-A](#jvms-4.6-200-A.1) 指定的所有位都保留, 以备将来使用。在生成 `class` 文件时应该将这些位置为 0; Java 虚拟机实现将会忽略这些位。

- name_index

  The value of the `name_index` item must be a valid index into the `constant_pool` table. The `constant_pool` entry at that index must be a `CONSTANT_Utf8_info` structure ([§4.4.7](#jvms-4.4.7)) representing either one of the special method names `<init>` or `<clinit>` ([§2.9](https://docs.oracle.com/javase/specs/jvms/se8/html/jvms-2.html#jvms-2.9)), or a valid unqualified name denoting a method ([§4.2.2](#jvms-4.2.2)).

  `name_index` 项的值必须是指向 `constant_pool` 表的有效索引。该索引处的 `constant_pool` 条目必须是 `CONSTANT_Utf8_info` 结构 ([§4.4.7](#jvms-4.4.7)), 用来表示特殊方法名 `<init>` 或 `<clinit>` 之一 ([§2.9](https://docs.oracle.com/javase/specs/jvms/se8/html/jvms-2.html#jvms-2.9)), 或者一个表示方法的有效非限定名称 ([§4.2.2](#jvms-4.2.2))。

- descriptor_index

  The value of the `descriptor_index` item must be a valid index into the `constant_pool` table. The `constant_pool` entry at that index must be a `CONSTANT_Utf8_info` structure representing a valid method descriptor ([§4.3.3](#jvms-4.3.3)).A future edition of this specification may require that the last parameter descriptor of the method descriptor is an array type if the `ACC_VARARGS` flag is set in the `access_flags`item.

  `descriptor_index` 项的值必须是指向 `constant_pool` 表的有效索引。该索引处的 `constant_pool` 条目必须是 `CONSTANT_Utf8_info` 结构, 用来表示一个有效的方法描述符 ([§4.3.3](#jvms-4.3.3))。本规范的未来版本可能会要求: 如果 `access_flags` 项中设置了 `ACC_VARARGS` 标志位, 则方法描述符的最后一个参数描述符必须是数组类型。

- attributes_count

  The value of the `attributes_count` item indicates the number of additional attributes of this method.

  `attributes_count` 项的值表示该方法附加属性的数量。

- attributes[]

  Each value of the `attributes` table must be an `attribute_info` structure ([§4.7](#jvms-4.7)).A method can have any number of optional attributes associated with it.The attributes defined by this specification as appearing in the `attributes` table of a `method_info` structure are listed in [Table 4.7-C](#jvms-4.7-320).The rules concerning attributes defined to appear in the `attributes` table of a `method_info` structure are given in [§4.7](#jvms-4.7).The rules concerning non-predefined attributes in the `attributes` table of a `method_info` structure are given in [§4.7.1](#jvms-4.7.1).

  `attributes` 表中的每一项都必须是 `attribute_info` 结构 ([§4.7](#jvms-4.7))。一个方法可以关联任意数量的可选属性。本规范定义为出现在 `method_info` 结构 `attributes` 表中的属性列在 [Table 4.7-C](#jvms-4.7-320) 中。关于定义为出现在 `method_info` 结构 `attributes` 表中的属性的规则, 在 [§4.7](#jvms-4.7) 中给出。关于 `method_info` 结构 `attributes` 表中非预定义属性的规则, 在 [§4.7.1](#jvms-4.7.1) 中给出。
