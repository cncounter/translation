
### 4.7.10. The `SourceFile` Attribute

### 4.7.10. `SourceFile` 属性

The `SourceFile` attribute is an optional fixed-length attribute in the `attributes` table of a `ClassFile` structure ([§4.1](#jvms-4.1)).

`SourceFile` 属性是 `ClassFile` 结构 ([§4.1](#jvms-4.1)) `attributes` 表中的一个可选的定长属性。

There may be at most one `SourceFile` attribute in the `attributes` table of a `ClassFile` structure.

`ClassFile` 结构的 `attributes` 表中最多只能有一个 `SourceFile` 属性。

The `SourceFile` attribute has the following format:

`SourceFile` 属性具有以下格式:

```
SourceFile_attribute {

}

```

The items of the `SourceFile_attribute` structure are as follows:

- attribute_name_index

- attribute_length

  The value of the `attribute_length` item of a `SourceFile_attribute` structure must be two.

  `SourceFile_attribute` 结构中 `attribute_length` 项的值必须是 2。

- sourcefile_index

  The value of the `sourcefile_index` item must be a valid index into the `constant_pool` table. The `constant_pool` entry at that index must be a `CONSTANT_Utf8_info` structure ([§4.4.7](#jvms-4.4.7)) representing a string.

  `sourcefile_index` 项的值必须是指向 `constant_pool` 表的有效索引。该索引处的 `constant_pool` 条目必须是 `CONSTANT_Utf8_info` 结构 ([§4.4.7](#jvms-4.4.7)), 用来表示一个字符串。

  The string referenced by the `sourcefile_index` item will be interpreted as indicating the name of the source file from which this `class` file was compiled. It will not be interpreted as indicating the name of a directory containing the file or an absolute path name for the file; such platform-specific additional information must be supplied by the run-time interpreter or development tool at the time the file name is actually used.

  `sourcefile_index` 项引用的字符串将被解释为表示编译出该 `class` 文件的源文件名称。它不会被解释为表示包含该文件的目录名称, 或该文件的绝对路径名; 这类与平台相关的附加信息, 必须在实际使用该文件名时由运行时解释器或开发工具提供。

### 4.7.12. The `LineNumberTable` Attribute

### 4.7.12. `LineNumberTable` 属性

The `LineNumberTable` attribute is an optional variable-length attribute in the `attributes` table of a `Code` attribute ([§4.7.3](#jvms-4.7.3)). It may be used by debuggers to determine which part of the `code` array corresponds to a given line number in the original source file.

`LineNumberTable` 属性是 `Code` 属性 ([§4.7.3](#jvms-4.7.3)) `attributes` 表中的一个可选变长属性。调试器可以使用它来确定 `code` 数组的哪一部分对应于原始源文件中的某个给定行号。

If multiple `LineNumberTable` attributes are present in the `attributes` table of a `Code` attribute, then they may appear in any order.

如果 `Code` 属性的 `attributes` 表中存在多个 `LineNumberTable` 属性, 那么它们可以以任意顺序出现。

There may be more than one `LineNumberTable` attribute *per line of a source file* in the `attributes` table of a `Code` attribute. That is, `LineNumberTable` attributes may together represent a given line of a source file, and need not be one-to-one with source lines.

在 `Code` 属性的 `attributes` 表中, *源文件的每一行* 都可能有多于一个 `LineNumberTable` 属性。也就是说, `LineNumberTable` 属性可以共同表示源文件的某一行, 而不必与源代码行一一对应。

The `LineNumberTable` attribute has the following format:

`LineNumberTable` 属性具有以下格式:

```
LineNumberTable_attribute {
    u2 attribute_name_index;
    u4 attribute_length;
    u2 line_number_table_length;
    {   u2 start_pc;
        u2 line_number;	
    } line_number_table[line_number_table_length];
}

```

The items of the `LineNumberTable_attribute` structure are as follows:

`LineNumberTable_attribute` 结构中的项如下:

- attribute_name_index

  The value of the `attribute_name_index` item must be a valid index into the `constant_pool` table. The `constant_pool` entry at that index must be a `CONSTANT_Utf8_info` structure ([§4.4.7](#jvms-4.4.7)) representing the string "`LineNumberTable`".

  `attribute_name_index` 项的值必须是指向 `constant_pool` 表的有效索引。该索引处的 `constant_pool` 条目必须是 `CONSTANT_Utf8_info` 结构 ([§4.4.7](#jvms-4.4.7)), 用来表示字符串 "`LineNumberTable`"。

- attribute_length

  The value of the `attribute_length` item indicates the length of the attribute, excluding the initial six bytes.

  `attribute_length` 项的值表示该属性的长度, 不包含最初的六个字节。

- line_number_table_length

  The value of the `line_number_table_length` item indicates the number of entries in the `line_number_table` array.

  `line_number_table_length` 项的值表示 `line_number_table` 数组中条目的数量。

- line_number_table[]

  Each entry in the `line_number_table` array indicates that the line number in the original source file changes at a given point in the `code` array. Each `line_number_table` entry must contain the following two items:

  `line_number_table` 数组中的每个条目都表示: 原始源文件中的行号在 `code` 数组的某个给定位置发生了变化。每个 `line_number_table` 条目必须包含以下两项:

  - start_pc

    The value of the `start_pc` item must indicate the index into the `code` array at which the code for a new line in the original source file begins.The value of `start_pc` must be less than the value of the `code_length` item of the `Code` attribute of which this `LineNumberTable` is an attribute.

    `start_pc` 项的值必须表示 `code` 数组中原始源文件新的一行代码开始处的索引。`start_pc` 的值必须小于该 `LineNumberTable` 所从属的 `Code` 属性中 `code_length` 项的值。

  - line_number

    The value of the `line_number` item must give the corresponding line number in the original source file.

    `line_number` 项的值必须给出原始源文件中对应的行号。

### 4.7.13. The `LocalVariableTable` Attribute

### 4.7.13. `LocalVariableTable` 属性

The `LocalVariableTable` attribute is an optional variable-length attribute in the `attributes` table of a `Code` attribute ([§4.7.3](#jvms-4.7.3)). It may be used by debuggers to determine the value of a given local variable during the execution of a method.

`LocalVariableTable` 属性是 `Code` 属性 ([§4.7.3](#jvms-4.7.3)) `attributes` 表中的一个可选变长属性。调试器可以使用它在方法执行期间确定某个给定局部变量的值。

If multiple `LocalVariableTable` attributes are present in the `attributes` table of a `Code` attribute, then they may appear in any order.

如果 `Code` 属性的 `attributes` 表中存在多个 `LocalVariableTable` 属性, 那么它们可以以任意顺序出现。

There may be no more than one `LocalVariableTable` attribute *per local variable* in the `attributes` table of a `Code` attribute.

在 `Code` 属性的 `attributes` 表中, *每个局部变量* 最多只能有一个 `LocalVariableTable` 属性。

The `LocalVariableTable` attribute has the following format:

`LocalVariableTable` 属性具有以下格式:

```
LocalVariableTable_attribute {
    u2 attribute_name_index;
    u4 attribute_length;
    u2 local_variable_table_length;
    {   u2 start_pc;
        u2 length;
        u2 name_index;
        u2 descriptor_index;
        u2 index;
    } local_variable_table[local_variable_table_length];
}

```

The items of the `LocalVariableTable_attribute` structure are as follows:

`LocalVariableTable_attribute` 结构中的项如下:

- attribute_name_index

  The value of the `attribute_name_index` item must be a valid index into the `constant_pool` table. The `constant_pool` entry at that index must be a `CONSTANT_Utf8_info` structure ([§4.4.7](#jvms-4.4.7)) representing the string "`LocalVariableTable`".

  `attribute_name_index` 项的值必须是指向 `constant_pool` 表的有效索引。该索引处的 `constant_pool` 条目必须是 `CONSTANT_Utf8_info` 结构 ([§4.4.7](#jvms-4.4.7)), 用来表示字符串 "`LocalVariableTable`"。

- attribute_length

  The value of the `attribute_length` item indicates the length of the attribute, excluding the initial six bytes.

  `attribute_length` 项的值表示该属性的长度, 不包含最初的六个字节。

- local_variable_table_length

  The value of the `local_variable_table_length` item indicates the number of entries in the `local_variable_table` array.

  `local_variable_table_length` 项的值表示 `local_variable_table` 数组中条目的数量。

- local_variable_table[]

  Each entry in the `local_variable_table` array indicates a range of `code` array offsets within which a local variable has a value. It also indicates the index into the local variable array of the current frame at which that local variable can be found. Each entry must contain the following five items:

  `local_variable_table` 数组中的每个条目都表示一段 `code` 数组偏移量范围, 局部变量在该范围内有值。它还表示当前栈帧(frame)的局部变量数组中可以找到该局部变量的索引。每个条目必须包含以下五项:

  - start_pc, length

    The given local variable must have a value at indices into the `code` array in the interval [`start_pc`, `start_pc + length`), that is, between `start_pc` inclusive and `start_pc + length` exclusive.The value of `start_pc` must be a valid index into the `code` array of this `Code` attribute and must be the index of the opcode of an instruction.The value of `start_pc + length` must either be a valid index into the `code` array of this `Code` attribute and be the index of the opcode of an instruction, or it must be the first index beyond the end of that `code` array.

    给定的局部变量在 `code` 数组索引区间 [`start_pc`, `start_pc + length`) 内必须有值, 也就是说, 从 `start_pc`(含)到 `start_pc + length`(不含)之间。`start_pc` 的值必须是该 `Code` 属性 `code` 数组中的有效索引, 并且必须是某条指令操作码的索引。`start_pc + length` 的值要么必须是该 `Code` 属性 `code` 数组中的有效索引并且是某条指令操作码的索引, 要么必须是该 `code` 数组末尾之后的第一个索引。

  - name_index

    The value of the `name_index` item must be a valid index into the `constant_pool` table. The `constant_pool` entry at that index must contain a `CONSTANT_Utf8_info` structure ([§4.4.7](#jvms-4.4.7)) representing a valid unqualified name denoting a local variable ([§4.2.2](#jvms-4.2.2)).

    `name_index` 项的值必须是指向 `constant_pool` 表的有效索引。该索引处的 `constant_pool` 条目必须包含 `CONSTANT_Utf8_info` 结构 ([§4.4.7](#jvms-4.4.7)), 用来表示一个表示局部变量的有效非限定名称 ([§4.2.2](#jvms-4.2.2))。

  - descriptor_index

    The value of the `descriptor_index` item must be a valid index into the `constant_pool` table. The `constant_pool` entry at that index must contain a `CONSTANT_Utf8_info`structure ([§4.4.7](#jvms-4.4.7)) representing a field descriptor which encodes the type of a local variable in the source program ([§4.3.2](#jvms-4.3.2)).

    `descriptor_index` 项的值必须是指向 `constant_pool` 表的有效索引。该索引处的 `constant_pool` 条目必须包含 `CONSTANT_Utf8_info` 结构 ([§4.4.7](#jvms-4.4.7)), 用来表示一个字段描述符, 该描述符编码了源程序中局部变量的类型 ([§4.3.2](#jvms-4.3.2))。

  - index

    The given local variable must be at `index` in the local variable array of the current frame.If the local variable at `index` is of type `double` or `long`, it occupies both `index` and `index + 1`.

    给定的局部变量必须位于当前栈帧局部变量数组中的 `index` 处。如果 `index` 处的局部变量是 `double` 或 `long` 类型, 则它同时占用 `index` 和 `index + 1`。

### 4.7.15. The `Deprecated` Attribute

```
}

```

The items of the `Deprecated_attribute` structure are as follows:

`Deprecated_attribute` 结构中的项如下:

- attribute_name_index

  The value of the `attribute_name_index` item must be a valid index into the `constant_pool` table. The `constant_pool` entry at that index must be a `CONSTANT_Utf8_info` structure ([§4.4.7](#jvms-4.4.7)) representing the string "`Deprecated`".

  `attribute_name_index` 项的值必须是指向 `constant_pool` 表的有效索引。该索引处的 `constant_pool` 条目必须是 `CONSTANT_Utf8_info` 结构 ([§4.4.7](#jvms-4.4.7)), 用来表示字符串 "`Deprecated`"。

- attribute_length

  The value of the `attribute_length` item must be zero.

  `attribute_length` 项的值必须是 0。

### 4.7.16. The `RuntimeVisibleAnnotations` Attribute

### 4.7.16. `RuntimeVisibleAnnotations` 属性

The `RuntimeVisibleAnnotations` attribute is a variable-length attribute in the `attributes` table of a `ClassFile`, `field_info`, or `method_info` structure ([§4.1](#jvms-4.1), [§4.5](#jvms-4.5), [§4.6](#jvms-4.6)). The`RuntimeVisibleAnnotations` attribute records run-time visible annotations on the declaration of the corresponding class, field, or method. The Java Virtual Machine must make these annotations available so they can be returned by the appropriate reflective APIs.

`RuntimeVisibleAnnotations` 属性是 `ClassFile`、`field_info` 或 `method_info` 结构 ([§4.1](#jvms-4.1), [§4.5](#jvms-4.5), [§4.6](#jvms-4.6)) `attributes` 表中的一个变长属性。`RuntimeVisibleAnnotations` 属性记录了相应类、字段或方法声明上的运行期可见注解(annotation)。Java 虚拟机必须使这些注解可用, 以便它们能够被相应的反射 API 返回。

There may be at most one `RuntimeVisibleAnnotations` attribute in the `attributes` table of a `ClassFile`, `field_info`, or `method_info` structure.

`ClassFile`、`field_info` 或 `method_info` 结构的 `attributes` 表中最多只能有一个 `RuntimeVisibleAnnotations` 属性。

The `RuntimeVisibleAnnotations` attribute has the following format:

`RuntimeVisibleAnnotations` 属性具有以下格式:

```
RuntimeVisibleAnnotations_attribute {
    u2         attribute_name_index;
    u4         attribute_length;
    u2         num_annotations;
    annotation annotations[num_annotations];
}

```

The items of the `RuntimeVisibleAnnotations_attribute` structure are as follows:

`RuntimeVisibleAnnotations_attribute` 结构中的项如下:

- attribute_name_index

  The value of the `attribute_name_index` item must be a valid index into the `constant_pool` table. The `constant_pool` entry at that index must be a `CONSTANT_Utf8_info` structure ([§4.4.7](#jvms-4.4.7)) representing the string "`RuntimeVisibleAnnotations`".

  `attribute_name_index` 项的值必须是指向 `constant_pool` 表的有效索引。该索引处的 `constant_pool` 条目必须是 `CONSTANT_Utf8_info` 结构 ([§4.4.7](#jvms-4.4.7)), 用来表示字符串 "`RuntimeVisibleAnnotations`"。

- attribute_length

  The value of the `attribute_length` item indicates the length of the attribute, excluding the initial six bytes.

  `attribute_length` 项的值表示该属性的长度, 不包含最初的六个字节。

- num_annotations

  The value of the `num_annotations` item gives the number of run-time visible annotations represented by the structure.

  `num_annotations` 项的值给出该结构所表示的运行期可见注解的数量。

- annotations[]

  Each entry in the `annotations` table represents a single run-time visible annotation on a declaration. The `annotation` structure has the following format:

  `annotations` 表中的每个条目都表示声明上的单个运行期可见注解。`annotation` 结构具有以下格式:

  ```
  annotation {
      u2 type_index;
      u2 num_element_value_pairs;
      {   u2            element_name_index;
          element_value value;
      } element_value_pairs[num_element_value_pairs];
  }
  ```

  The items of the `annotation` structure are as follows:

  `annotation` 结构中的项如下:

  - type_index

    The value of the `type_index` item must be a valid index into the `constant_pool` table. The `constant_pool` entry at that index must be a `CONSTANT_Utf8_info` structure ([§4.4.7](#jvms-4.4.7)) representing a field descriptor ([§4.3.2](#jvms-4.3.2)). The field descriptor denotes the type of the annotation represented by this `annotation` structure.

    `type_index` 项的值必须是指向 `constant_pool` 表的有效索引。该索引处的 `constant_pool` 条目必须是 `CONSTANT_Utf8_info` 结构 ([§4.4.7](#jvms-4.4.7)), 用来表示一个字段描述符 ([§4.3.2](#jvms-4.3.2))。该字段描述符表示该 `annotation` 结构所代表注解的类型。

  - num_element_value_pairs

    The value of the `num_element_value_pairs` item gives the number of element-value pairs of the annotation represented by this `annotation` structure.

    `num_element_value_pairs` 项的值给出该 `annotation` 结构所代表注解的"元素-值对"(element-value pair)的数量。

  - element_value_pairs[]

    Each value of the `element_value_pairs` table represents a single element-value pair in the annotation represented by this `annotation` structure. Each `element_value_pairs` entry contains the following two items:

    `element_value_pairs` 表中的每个值都表示该 `annotation` 结构所代表注解中的单个元素-值对。每个 `element_value_pairs` 条目包含以下两项:

    - element_name_index

      The value of the `element_name_index` item must be a valid index into the `constant_pool` table. The `constant_pool` entry at that index must be a`CONSTANT_Utf8_info` structure ([§4.4.7](#jvms-4.4.7)). The `constant_pool` entry denotes the name of the element of the element-value pair represented by this `element_value_pairs` entry.In other words, the entry denotes an element of the annotation type specified by `type_index`.

      `element_name_index` 项的值必须是指向 `constant_pool` 表的有效索引。该索引处的 `constant_pool` 条目必须是 `CONSTANT_Utf8_info` 结构 ([§4.4.7](#jvms-4.4.7))。该 `constant_pool` 条目表示该 `element_value_pairs` 条目所代表元素-值对中元素的名称。换句话说, 该条目表示由 `type_index` 指定的注解类型的一个元素。

    - value

      The value of the `value` item represents the value of the element-value pair represented by this `element_value_pairs` entry.

      `value` 项的值表示该 `element_value_pairs` 条目所代表元素-值对的值。

#### 4.7.16.1. The `element_value` structure

#### 4.7.16.1. `element_value` 结构

The `element_value` structure is a discriminated union representing the value of an element-value pair. It has the following format:

`element_value` 结构是一个可辨识联合(discriminated union), 用来表示元素-值对的值。它具有以下格式:

```
element_value {
    u1 tag;
    union {
        u2 const_value_index;

        {   u2 type_name_index;
            u2 const_name_index;
        } enum_const_value;

        u2 class_info_index;

        annotation annotation_value;

        {   u2            num_values;
            element_value values[num_values];
        } array_value;
    } value;
}

```

The `tag` item uses a single ASCII character to indicate the type of the value of the element-value pair. This determines which item of the `value` union is in use. [Table 4.7.16.1-A](#jvms-4.7.16.1-130) shows the valid characters for the `tag` item, the type indicated by each character, and the item used in the `value` union for each character. The table's fourth column is used in the description below of one item of the `value` union.

`tag` 项使用单个 ASCII 字符来指示元素-值对的值的类型。这决定了 `value` 联合中哪一项正在被使用。[Table 4.7.16.1-A](#jvms-4.7.16.1-130) 给出了 `tag` 项的有效字符、每个字符所指示的类型, 以及每个字符在 `value` 联合中所使用的项。该表的第四列会在下文描述 `value` 联合的某一项时用到。

**Table 4.7.16.1-A. Interpretation of tag values as types**

**Table 4.7.16.1-A. tag 值作为类型的解释**

| `tag` Item | Type            | `value` Item        | Constant Type      |
| ---------- | --------------- | ------------------- | ------------------ |
| `B`        | `byte`          | `const_value_index` | `CONSTANT_Integer` |
| `C`        | `char`          | `const_value_index` | `CONSTANT_Integer` |
| `D`        | `double`        | `const_value_index` | `CONSTANT_Double`  |
| `F`        | `float`         | `const_value_index` | `CONSTANT_Float`   |
| `I`        | `int`           | `const_value_index` | `CONSTANT_Integer` |
| `J`        | `long`          | `const_value_index` | `CONSTANT_Long`    |
| `S`        | `short`         | `const_value_index` | `CONSTANT_Integer` |
| `Z`        | `boolean`       | `const_value_index` | `CONSTANT_Integer` |
| `s`        | `String`        | `const_value_index` | `CONSTANT_Utf8`    |
| `e`        | Enum type       | `enum_const_value`  | *Not applicable*   |
| `c`        | `Class`         | `class_info_index`  | *Not applicable*   |
| `@`        | Annotation type | `annotation_value`  | *Not applicable*   |
| `[`        | Array type      | `array_value`       | *Not applicable*   |

The `value` item represents the value of an element-value pair. The item is a union, whose own items are as follows:

`value` 项表示元素-值对的值。该项是一个联合, 它自身的项如下:

- const_value_index

  The `const_value_index` item denotes either a primitive constant value or a `String` literal as the value of this element-value pair.The value of the `const_value_index` item must be a valid index into the `constant_pool` table. The `constant_pool` entry at that index must be of a type appropriate to the `tag`item, as specified in the fourth column of [Table 4.7.16.1-A](#jvms-4.7.16.1-130).

  `const_value_index` 项表示一个基本类型的常量值或一个 `String` 字面量作为该元素-值对的值。`const_value_index` 项的值必须是指向 `constant_pool` 表的有效索引。该索引处的 `constant_pool` 条目必须是适合该 `tag` 项的类型, 如 [Table 4.7.16.1-A](#jvms-4.7.16.1-130) 第四列所指定。

- enum_const_value

  The `enum_const_value` item denotes an enum constant as the value of this element-value pair.The `enum_const_value` item consists of the following two items:

  `enum_const_value` 项表示一个枚举常量作为该元素-值对的值。`enum_const_value` 项由以下两项组成:

  - type_name_index

    The value of the `type_name_index` item must be a valid index into the `constant_pool` table. The `constant_pool` entry at that index must be a `CONSTANT_Utf8_info`structure ([§4.4.7](#jvms-4.4.7)) representing a field descriptor ([§4.3.2](#jvms-4.3.2)). The `constant_pool` entry gives the internal form of the binary name of the type of the enum constant represented by this `element_value` structure ([§4.2.1](#jvms-4.2.1)).

    `type_name_index` 项的值必须是指向 `constant_pool` 表的有效索引。该索引处的 `constant_pool` 条目必须是 `CONSTANT_Utf8_info` 结构 ([§4.4.7](#jvms-4.4.7)), 用来表示一个字段描述符 ([§4.3.2](#jvms-4.3.2))。该 `constant_pool` 条目给出该 `element_value` 结构所代表枚举常量类型的二进制名称的内部形式 ([§4.2.1](#jvms-4.2.1))。

  - const_name_index

    The value of the `const_name_index` item must be a valid index into the `constant_pool` table. The `constant_pool` entry at that index must be a `CONSTANT_Utf8_info`structure ([§4.4.7](#jvms-4.4.7)). The `constant_pool` entry gives the simple name of the enum constant represented by this `element_value` structure.

    `const_name_index` 项的值必须是指向 `constant_pool` 表的有效索引。该索引处的 `constant_pool` 条目必须是 `CONSTANT_Utf8_info` 结构 ([§4.4.7](#jvms-4.4.7))。该 `constant_pool` 条目给出该 `element_value` 结构所代表枚举常量的简单名称(simple name)。

- class_info_index

  The `class_info_index` item denotes a class literal as the value of this element-value pair.The `class_info_index` item must be a valid index into the `constant_pool` table. The `constant_pool` entry at that index must be a `CONSTANT_Utf8_info` structure ([§4.4.7](#jvms-4.4.7)) representing a return descriptor ([§4.3.3](#jvms-4.3.3)). The return descriptor gives the type corresponding to the class literal represented by this `element_value` structure. Types correspond to class literals as follows:

  `class_info_index` 项表示一个类字面量(class literal)作为该元素-值对的值。`class_info_index` 项必须是指向 `constant_pool` 表的有效索引。该索引处的 `constant_pool` 条目必须是 `CONSTANT_Utf8_info` 结构 ([§4.4.7](#jvms-4.4.7)), 用来表示一个返回描述符 ([§4.3.3](#jvms-4.3.3))。该返回描述符给出该 `element_value` 结构所代表类字面量对应的类型。类型与类字面量的对应关系如下:

  - For a class literal C`.``class`, where C is the name of a class, interface, or array type, the corresponding type is C. The return descriptor in the `constant_pool` will be an *ObjectType* or an *ArrayType*.

    对于类字面量 C`.``class`, 其中 C 是类、接口或数组类型的名称, 对应的类型是 C。`constant_pool` 中的返回描述符将是一个 *ObjectType* 或 *ArrayType*。

  - For a class literal p`.``class`, where p is the name of a primitive type, the corresponding type is p. The return descriptor in the `constant_pool` will be a *BaseType* character.

    对于类字面量 p`.``class`, 其中 p 是基本类型的名称, 对应的类型是 p。`constant_pool` 中的返回描述符将是一个 *BaseType* 字符。

  - For a class literal `void``.``class`, the corresponding type is `void`. The return descriptor in the `constant_pool` will be *V*.

    对于类字面量 `void``.``class`, 对应的类型是 `void`。`constant_pool` 中的返回描述符将是 *V*。

  For example, the class literal `Object.class` corresponds to the type `Object`, so the `constant_pool` entry is `Ljava/lang/Object;`, whereas the class literal `int.class` corresponds to the type `int`, so the `constant_pool` entry is `I`.The class literal `void.class` corresponds to `void`, so the `constant_pool` entry is *V*, whereas the class literal `Void.class` corresponds to the type `Void`, so the `constant_pool` entry is `Ljava/lang/Void;`.

  例如, 类字面量 `Object.class` 对应类型 `Object`, 因此 `constant_pool` 条目是 `Ljava/lang/Object;`; 而类字面量 `int.class` 对应类型 `int`, 因此 `constant_pool` 条目是 `I`。类字面量 `void.class` 对应 `void`, 因此 `constant_pool` 条目是 *V*; 而类字面量 `Void.class` 对应类型 `Void`, 因此 `constant_pool` 条目是 `Ljava/lang/Void;`。

- annotation_value

  The `annotation_value` item denotes a "nested" annotation as the value of this element-value pair.The value of the `annotation_value` item is an `annotation` structure ([§4.7.16](#jvms-4.7.16)) that gives the annotation represented by this `element_value` structure.

  `annotation_value` 项表示一个"嵌套的"注解作为该元素-值对的值。`annotation_value` 项的值是一个 `annotation` 结构 ([§4.7.16](#jvms-4.7.16)), 给出该 `element_value` 结构所代表的注解。

- array_value

  The `array_value` item denotes an array as the value of this element-value pair.The `array_value` item consists of the following two items:

  `array_value` 项表示一个数组作为该元素-值对的值。`array_value` 项由以下两项组成:

  - num_values

    The value of the `num_values` item gives the number of elements in the array represented by this `element_value` structure.

    `num_values` 项的值给出该 `element_value` 结构所代表数组中元素的数量。

  - values[]

    Each value in the `values` table gives the corresponding element of the array represented by this `element_value` structure.

    `values` 表中的每个值给出该 `element_value` 结构所代表数组中对应的元素。
