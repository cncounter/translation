## 4.5. Fields

## 4.5. 字段

Each field is described by a `field_info` structure.

每个字段都由一个 `field_info` 结构来描述。

No two fields in one `class` file may have the same name and descriptor ([§4.3.2](#jvms-4.3.2)).

同一个 `class` 文件中, 不能有两个字段具有相同的名称和描述符 ([§4.3.2](#jvms-4.3.2))。

The structure has the following format:

该结构具有以下格式:

```
field_info {
    u2             access_flags;
    u2             name_index;
    u2             descriptor_index;
    u2             attributes_count;
    attribute_info attributes[attributes_count];
}

```

The items of the `field_info` structure are as follows:

`field_info` 结构中的项如下:

- access_flags

  The value of the `access_flags` item is a mask of flags used to denote access permission to and properties of this field. The interpretation of each flag, when set, is specified in [Table 4.5-A](#jvms-4.5-200-A.1).

  `access_flags` 项的值是一个标志位掩码, 用来表示该字段的访问权限以及相关特性。每个标志位被设置时的含义在 [Table 4.5-A](#jvms-4.5-200-A.1) 中指定。

**Table 4.5-A. Field access and property flags**

**Table 4.5-A. 字段的访问与特性标志**

| Flag Name        | Value  | Interpretation                           |
| ---------------- | ------ | ---------------------------------------- |
| `ACC_PUBLIC`     | 0x0001 | Declared `public`; may be accessed from outside its package. |
| `ACC_PRIVATE`    | 0x0002 | Declared `private`; usable only within the defining class. |
| `ACC_PROTECTED`  | 0x0004 | Declared `protected`; may be accessed within subclasses. |
| `ACC_STATIC`     | 0x0008 | Declared `static`. |
| `ACC_FINAL`      | 0x0010 | Declared `final`; never directly assigned to after object construction (JLS §17.5). |
| `ACC_VOLATILE`   | 0x0040 | Declared `volatile`; cannot be cached. |
| `ACC_TRANSIENT`  | 0x0080 | Declared `transient`; not written or read by a persistent object manager. |
| `ACC_SYNTHETIC`  | 0x1000 | Declared synthetic; not present in the source code. |
| `ACC_ENUM`       | 0x4000 | Declared as an element of an `enum`. |

| Flag Name        | Value  | Interpretation                           |
| ---------------- | ------ | ---------------------------------------- |
| `ACC_PUBLIC`     | 0x0001 | 声明为 `public`; 可以被其他包(package)所访问。 |
| `ACC_PRIVATE`    | 0x0002 | 声明为 `private`; 只能在定义该字段的类内部使用。 |
| `ACC_PROTECTED`  | 0x0004 | 声明为 `protected`; 可以在子类(subclasses)中访问。 |
| `ACC_STATIC`     | 0x0008 | 声明为 `static`。 |
| `ACC_FINAL`      | 0x0010 | 声明为 `final`; 在对象构造完成后不能再直接赋值 (JLS §17.5)。 |
| `ACC_VOLATILE`   | 0x0040 | 声明为 `volatile`; 不能被缓存。 |
| `ACC_TRANSIENT`  | 0x0080 | 声明为 `transient`; 不会被持久化对象管理器写入或读取。 |
| `ACC_SYNTHETIC`  | 0x1000 | 声明为 synthetic(合成); 即在 Java 源代码中不存在。 |
| `ACC_ENUM`       | 0x4000 | 声明为 `enum` 的一个元素。 |

  Fields of classes may set any of the flags in [Table 4.5-A](#jvms-4.5-200-A.1). However, each field of a class may have at most one of its `ACC_PUBLIC`, `ACC_PRIVATE`, and `ACC_PROTECTED` flags set (JLS §8.3.1), and must not have both its `ACC_FINAL` and `ACC_VOLATILE` flags set (JLS §8.3.1.4).

  类的字段可以设置 [Table 4.5-A](#jvms-4.5-200-A.1) 中的任意标志位。但是, 类的每个字段最多只能设置 `ACC_PUBLIC`、`ACC_PRIVATE` 和 `ACC_PROTECTED` 中的一个标志位 (JLS §8.3.1), 并且不能同时设置 `ACC_FINAL` 和 `ACC_VOLATILE` 标志位 (JLS §8.3.1.4)。

  Fields of interfaces must have their `ACC_PUBLIC`, `ACC_STATIC`, and `ACC_FINAL` flags set; they may have their `ACC_SYNTHETIC` flag set and must not have any of the other flags in [Table 4.5-A](#jvms-4.5-200-A.1) set (JLS §9.3).

  接口的字段必须设置 `ACC_PUBLIC`、`ACC_STATIC` 和 `ACC_FINAL` 标志位; 它们可以设置 `ACC_SYNTHETIC` 标志位, 但不能设置 [Table 4.5-A](#jvms-4.5-200-A.1) 中的任何其他标志位 (JLS §9.3)。

  The `ACC_SYNTHETIC` flag indicates that this field was generated by a compiler and does not appear in source code.

  `ACC_SYNTHETIC` 标志位表明该字段是由编译器生成的, 在源代码中并不存在。

  The `ACC_ENUM` flag indicates that this field is used to hold an element of an enumerated type.

  `ACC_ENUM` 标志位表明该字段用于保存枚举类型的一个元素。

  All bits of the `access_flags` item not assigned in [Table 4.5-A](#jvms-4.5-200-A.1) are reserved for future use. They should be set to zero in generated `class` files and should be ignored by Java Virtual Machine implementations.

  `access_flags` 项中未在 [Table 4.5-A](#jvms-4.5-200-A.1) 指定的所有位都保留, 以备将来使用。在生成 `class` 文件时应该将这些位置为 0; Java 虚拟机实现将会忽略这些位。

- name_index

  The value of the `name_index` item must be a valid index into the `constant_pool` table. The `constant_pool` entry at that index must be a `CONSTANT_Utf8_info` structure ([§4.4.7](#jvms-4.4.7)) which represents a valid unqualified name denoting a field ([§4.2.2](#jvms-4.2.2)).

  `name_index` 项的值必须是指向 `constant_pool` 表的有效索引。该索引处的 `constant_pool` 条目必须是 `CONSTANT_Utf8_info` 结构 ([§4.4.7](#jvms-4.4.7)), 用来表示一个表示字段的有效非限定名称 ([§4.2.2](#jvms-4.2.2))。

- descriptor_index

  The value of the `descriptor_index` item must be a valid index into the `constant_pool` table. The `constant_pool` entry at that index must be a `CONSTANT_Utf8_info` structure ([§4.4.7](#jvms-4.4.7)) which represents a valid field descriptor ([§4.3.2](#jvms-4.3.2)).

  `descriptor_index` 项的值必须是指向 `constant_pool` 表的有效索引。该索引处的 `constant_pool` 条目必须是 `CONSTANT_Utf8_info` 结构 ([§4.4.7](#jvms-4.4.7)), 用来表示一个有效的字段描述符 ([§4.3.2](#jvms-4.3.2))。

- attributes_count

  The value of the `attributes_count` item indicates the number of additional attributes of this field.

  `attributes_count` 项的值表示该字段附加属性的数量。

- attributes[]

  Each value of the `attributes` table must be an `attribute_info` structure ([§4.7](#jvms-4.7)).A field can have any number of optional attributes associated with it.The attributes defined by this specification as appearing in the `attributes` table of a `field_info` structure are listed in [Table 4.7-C](#jvms-4.7-320).The rules concerning attributes defined to appear in the `attributes` table of a `field_info` structure are given in [§4.7](#jvms-4.7).The rules concerning non-predefined attributes in the `attributes` table of a `field_info` structure are given in [§4.7.1](#jvms-4.7.1).

  `attributes` 表中的每一项都必须是 `attribute_info` 结构 ([§4.7](#jvms-4.7))。一个字段可以关联任意数量的可选属性。本规范定义为出现在 `field_info` 结构 `attributes` 表中的属性列在 [Table 4.7-C](#jvms-4.7-320) 中。关于定义为出现在 `field_info` 结构 `attributes` 表中的属性的规则, 在 [§4.7](#jvms-4.7) 中给出。关于 `field_info` 结构 `attributes` 表中非预定义属性的规则, 在 [§4.7.1](#jvms-4.7.1) 中给出。
